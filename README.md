# 🍏 Liquid Game Hub — Игры и Софт (.ZIP / Google Drive)

Современный веб-хаб для загрузки игр и программ в формате `.ZIP Portable` с Google Drive в дизайне **Apple Liquid Glass (iOS 27 / macOS Sequoia)**.

## 🚀 Как открыть локально
Просто дважды кликните по файлу `index.html` или откройте его в любом браузере (Chrome, Edge, Safari, Firefox).

## 🌐 Как опубликовать на GitHub Pages (Бесплатно):
1. Создайте новый репозиторий на GitHub (например, `liquid-hub`).
2. Загрузите файлы `index.html` и `README.md` в корень репозитория.
3. Перейдите в **Settings** репозитория -> раздел **Pages**.
4. В поле **Build and deployment -> Source** выберите **Deploy from a branch**, ветка `main` / `root`.
5. Через 30 секунд ваш сайт будет доступен по ссылке `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## 👑 Авторизация Создателя:
- По кнопке **«Войти через Google»** введите почту: `metaquestvropen@gmail.com` (или нажмите кнопку «Я создатель в 1 клик»).
- После входа сайт сохранит сессию в `cookies` и `localStorage`.
- Появится специальная кнопка **«+ Создать раздачу»**, баннер создателя и кнопка **«Экспорт games.json»**.
